# TaskFlow

A simple, clean, and production-quality Todo application built with the MERN stack (MongoDB, Express.js, React.js, and Node.js).

Please refer to the main [README.md](../README.md) in the project root for full documentation, installation instructions, database creation guide, and presentation notes.

## Quick Commands

### Backend:
```bash
cd backend
npm install
npm run dev
```

### Frontend:
```bash
cd frontend
npm install
npm run dev
```
